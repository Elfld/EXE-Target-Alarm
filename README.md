# 🎮 게임 시간 알림기 (EXE Target Alarm)

특정 게임(프로세스)이 실행 중일 때, **매 시간 특정 분(예: 매시 2분)**에 자동으로 알림을 보내주는 데스크톱 유틸리티입니다.

## ✨ 주요 기능

- 🎯 **프로세스 기반 감지**: 특정 exe 파일이 실행 중일 때만 알림 발송
- ⏰ **시간 기반 알림**: 매 시간 정해진 분(0-59)에 정확히 알림
- 🔔 **Toast 알림**: Windows 10/11 네이티브 알림 지원
- 🔊 **사운드 알림**: 시스템 사운드로 추가 알림 (ON/OFF 가능)
- 💾 **자동 설정 저장**: 프로그램 종료 시 설정 자동 저장 및 복원
- 📋 **실시간 로그**: 모든 이벤트를 로그로 확인
- 🌙 **다크 모드**: CustomTkinter 기반의 모던한 UI

## 🔧 기술 스택

- **Python 3.10+**
- **CustomTkinter**: 모던한 다크 모드 UI
- **psutil**: 프로세스 감지
- **win10toast-click** / **plyer**: Toast 알림
- **winsound**: 시스템 사운드 (Windows)

## 🎯 사용 방법

### 1. 타겟 프로세스 선택
- **[찾아보기]** 버튼을 클릭하여 감지할 exe 파일을 선택합니다.
- 예: `LeagueClient.exe`, `Minecraft.exe` 등

### 2. 알림 분 설정
- **0-59** 사이의 숫자를 입력합니다.
- 예: `2` 입력 시 → 매 시간 **XX:02**에 알림
- 예: `30` 입력 시 → 매 시간 **XX:30**에 알림

### 3. 사운드 설정
- **사운드 켜기** 스위치로 알림음 ON/OFF를 선택합니다.

### 4. 감시 시작
- **[감시 시작]** 버튼을 클릭합니다.
- 상태가 **🟢 감시 중**으로 변경됩니다.

### 5. 알림 확인
- 설정한 분이 되고 타겟 프로세스가 실행 중이면:
  - 📱 Toast 알림이 표시됩니다
  - 🔊 시스템 사운드가 재생됩니다 (설정 시)
  - 📋 로그에 기록됩니다

## 🧠 동작 원리 (Wall-clock Alarm)

```python
# 1초 간격으로 반복:
for each second:
    현재_시각 = datetime.now()

    # 조건 1: 현재 분이 설정한 알림 분과 일치?
    if 현재_시각.minute == 설정한_알림_분:

        # 조건 2: 이번 시간에 이미 알림을 보냈는가? (중복 방지)
        if 이번_시간에_알림_안보냄:

            # 조건 3: 타겟 프로세스가 실행 중인가?
            if 타겟_프로세스_실행중():
                알림_발송()
                이번_시간_알림_완료_표시()
```

### 중복 방지 로직
- 매 시간마다 **1번만** 알림을 보냅니다.
- 예: 14:02에 알림을 보냈다면, 14:02~14:59까지는 추가 알림을 보내지 않습니다.
- 15:02가 되면 다시 알림을 보냅니다.

## ⚙️ 설정 파일 (config.json)

```json
    "alert_minute": 2,
    "sound_enabled": true
}
```

## 🛡️ 예외 처리

- ✅ **프로세스 접근 권한 오류** → `psutil.AccessDenied` 자동 무시
- ✅ **유효하지 않은 분 입력** → 0-59 범위 검증
- ✅ **파일 선택 취소** → 안전하게 처리
- ✅ **라이브러리 미설치** → 경고 로그 출력 및 계속 실행

## 💡 활용 예시

### 게임 휴식 알림
- **상황**: 장시간 게임 플레이 시 휴식이 필요
- **설정**: 매 시간 0분에 알림 → 시간당 한 번씩 휴식 리마인더

### 게임 내 이벤트 알림
- **상황**: 매 시간 정각에 게임 내 이벤트 발생
- **설정**: 매 시간 55분에 알림 → 5분 전 미리 알림

### 눈 건강 관리
- **상황**: 20-20-20 규칙 (20분마다 20초간 휴식)
- **설정**: 매 시간 20분, 40분에 알림

## 🔍 문제 해결

### Toast 알림이 안 나타나요
```bash
pip install --upgrade win10toast-click
```

### 프로세스 감지가 안 돼요
- 관리자 권한으로 실행해보세요
- 정확한 프로세스명을 입력했는지 확인하세요 (예: `game.exe`)

### 사운드가 안 들려요
- Windows 시스템 볼륨을 확인하세요
- 사운드 스위치가 켜져 있는지 확인하세요
